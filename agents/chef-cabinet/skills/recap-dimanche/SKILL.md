# Récap du dimanche

Prêt à 20h (Europe/Paris). Lecture : 5 minutes. Charte : `rapport-design`,
couleur aubergine.

## Sources de données (Phase 1)
Le site te fournit dans le message : les rapports publiés de la semaine,
les retours utile / bof / inutile, la to-do, les décisions et les idées.
Toute donnée absente = « pas encore suivi ». Jamais d'estimation.

## Structure
1. En bref : 3 lignes (ce qui a avancé, ce qui a coincé, la priorité de la
   semaine prochaine).
2. Ta semaine : éditions du Journal publiées, tâches faites et restantes.
   En Phase 1, sommeil, séances, révisions et coût = « pas encore suivi ».
3. Tes décisions et les miennes : les décisions de la semaine, avec leur statut (maintenue / annulée par Marjana).
4. Tes retours : ce que les agents vont changer en conséquence.
5. La semaine qui vient : les 3 priorités proposées, à valider.
6. Boîte à idées : les idées notées dans la semaine (une seule sera promue
   par mois).

## Relecture avant d'écrire le fichier
Aucun chiffre inventé ; chaque décision a sa raison ; le ton est calme et
factuel ; aucune information sur l'employeur ou ses clients.
